
# CodeAlpha Stock Portfolio Tracker

## Description
A simple Python program that calculates the total investment
based on stock prices and quantities.

## Features
- User enters stock name
- User enters quantity
- Uses a dictionary for stock prices
- Calculates total investment
- Displays the result

## Technologies Used
- Python
- Dictionary
- Input/Output
- Basic Arithmetic

## How to Run

python stock_portfolio_tracker.py
